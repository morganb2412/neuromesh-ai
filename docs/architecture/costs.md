# Deployment cost gate

The GCP deployment is live in `moesautomationweekly`. Terraform created a dedicated Cloud SQL instance, Artifact Registry repository, runtime identity, secrets, scoped IAM, and Cloud Run service. Existing services and the existing SQL instance remain outside this module. The project has a **$40 monthly budget alert** with notifications at $10, $25, and $40; it watches total project spend, including preexisting workloads.

Release 0.3.0 reused these resources. Its Terraform apply reported **0 added, 1 Cloud Run service changed in place, 0 destroyed**. The one Cloud Build and a few bounded research/voice verification calls add usage-based cost but no new persistent baseline. The NCBI contact is an environment value, not a new Secret Manager resource.

Release 0.3.1 updated the same service in place with **0 added, 1 changed, 0 destroyed**. Public access is read-only. Admin questions use stored evidence by default; Gemini and Cloud voice require separate user actions. The deployment build and browser tests made no provider model or speech calls.

At 730 hours per month in `us-central1`, a new `db-f1-micro` Cloud SQL instance costs about **$7.67 compute** plus about **$1.70 for 10 GiB SSD**, before backup storage and network charges. The shared-core tier has no SLA. Cloud Run has a billing-account-wide free tier, but this project shares the billing account with other workloads, so no free allocation is assumed. Artifact Registry charges beyond its billing-account-wide 0.5 GiB-month free allocation. Cloud Build, Secret Manager, logging, and transfer may add small usage-based charges. The persistent baseline is therefore roughly **$10–$15/month at low traffic**, and **$20–$40/month** is a more prudent test budget. This is an estimate, not a cap.

The initial deployment kept ADK and Cloud TTS off. After a separate operator test approval, **Gemini 3.5 Flash-Lite and Cloud TTS Standard-J are enabled**. Admin questions default to indexed evidence without a model call; the Gemini switch opts into provider use. The app caps model investigations at 20/day with at most four calls and 768 output tokens per agent; Cloud TTS is capped at 20,000 characters/day. The selected Standard voice has a published first 4 million characters per month at no charge, then $4 per million; 20,000 characters every day would be 600,000 per 30-day month, or $2.40 if the free allocation were already exhausted. Gemini Flash-Lite cost depends on input/output tokens. Both provider endpoints require a separate operator token. Public visitors can browse indexed data but cannot submit investigations or trigger provider calls.

Budget alerts notify but **do not automatically stop billing**. Review [Cloud SQL](https://cloud.google.com/sql/pricing), [Cloud Run](https://cloud.google.com/run/pricing), [Artifact Registry](https://cloud.google.com/artifact-registry/pricing), [Text-to-Speech](https://cloud.google.com/text-to-speech/pricing), and [Gemini](https://cloud.google.com/gemini-enterprise-agent-platform/generative-ai/pricing) prices before changing capacity or enabling providers, because rates and free tiers change.

Terraform state contains generated database and operator secrets. Keep it outside Git in a private, encrypted state backend with tightly scoped access for ongoing use; the local state file is ignored by Git for this initial review. Never paste its contents into issues, logs, or commits.
