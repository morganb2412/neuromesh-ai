# Literature review notes

This is a source collection and review plan, not a completed literature synthesis. NeuroMesh has indexed a bounded local sample from OpenAlex, arXiv, and PubMed. A review must next screen relevant works, verify publication versions and identifiers, record inclusion criteria, and distinguish empirical memory evaluations from architectural proposals.

Search concepts: episodic memory in agents, semantic memory, temporal knowledge graphs, continual learning, retrieval-augmented generation, multi-hop reasoning, and knowledge correction. For each included work, record the task, model, retrieval method, dataset, outcome, limitations, and source URL. No claim about consensus or superiority is made here before that review.

Provider documentation: [OpenAlex Works](https://help.openalex.org/data/works/attributes/), [arXiv API](https://github.com/arXiv/arxiv-docs/blob/develop/source/help/api/user-manual.md), [PubMed E-utilities](https://www.ncbi.nlm.nih.gov/sites/books/NBK25499/).
